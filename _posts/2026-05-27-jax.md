MIT SuperCloud does not have JAX pre-installed, so you will need to set up a Python environment and install JAX yourself. It's a little bit tricky because the default user quota is not large enough to install JAX and its dependencies, so here's a guide to help you through the process.

*Verified on 05/28/2026*

*Provided by: Filippo Gaggioli*

## 0. Load Conda Base Environment

```bash
source /usr/local/anaconda/python-ML-2024b/bin/activate base
```

## 1. Create Python 3.13 Conda Environment

```bash
conda create --name py313 python=3.13 numpy scipy pandas matplotlib virtualenv
```

## 2. Activate Conda Environment and Create Virtual Environment

Activate the Conda environment:

```bash
conda activate py313
```

Create a virtual environment:

```bash
virtualenv ~/venv/my-folder-name
```

Example:
- Environment name = folder name

## 3. Activate Virtual Environment

```bash
source ~/venv/my-folder-name/bin/activate
```

## 4. Install Project and Dependencies

Inside the project folder:

```bash
pip install -e .
```

This installs the package in editable mode together with all required dependencies.

## 5. Preliminary GPU Setup (Recommended)

Run this before installing GPU support:

```bash
mkdir /state/partition1/user/$USER
export TMPDIR=/state/partition1/user/$USER
```

## 6. Optional: Install GPU Support for JAX

If a GPU is available:

```bash
pip install -U "jax[cuda12]"
```

This updates JAX and installs CUDA 12 support.

# Notes

- This setup was verified on 07/14/2025.
- The GPU installation step is optional.
- Using a separate virtual environment inside Conda helps isolate dependencies.
- `pip install -e .` is useful during development because local code changes are reflected immediately.
